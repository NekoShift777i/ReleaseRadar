ReleaseRadar — история изменений
===============================

Версия 1.2.0 — подготовка к выпуску
----------------------------------

Добавлено:
- Ручная проверка отдельных программ через кнопки Telegram.
- Постраничный выбор программ в команде /check.
- Параллельная проверка нескольких программ.
- Проверка структуры и параметров конфигурации.
- Настраиваемый срок действия кнопок уведомлений.
- Автоматическая очистка устаревших кнопок и служебных записей.
- Пропуск отдельных выпусков с указанием причины.
- Сохранение истории пропущенных выпусков в SQLite.
- Команда /skipped для просмотра истории пропусков.
- Дополнительные автоматические проверки основных функций.
- Отслеживание Actual Budget, Frigate NVR и HeliBoard.

Улучшено:
- Проверка авторизации команд и нажатий кнопок Telegram.
- Защита от одновременных проверок одной программы.
- Обработка ошибок получения выпусков и отображение состояния.
- Безопасное редактирование существующих сообщений Telegram.
- Сравнение версий и выбор подходящего выпуска.
- Защита от повторных нажатий и устаревших кнопок.
- Независимая отмена запросов подтверждения и пропуска.
- Исключение пропущенных выпусков из повторных уведомлений.
- Отображение дат пропусков по камчатскому времени.
- Документация по установке, настройке и обслуживанию.

Исправлено:
- Устранены отдельные ошибки при сохранении состояния в SQLite.
- Устранены повторные запросы проверки одной программы.
- Исправлена обработка устаревших запросов подтверждения.
- Исключена возможность отмены нового пропуска старой кнопкой.

Изменения базы данных:
- Добавлено поле created_at для кнопок уведомлений.
- Реализовано обновление структуры существующей базы.
- Добавлена таблица истории пропущенных выпусков.

Примечания:
- Подтверждение обновления изменяет сохранённую версию,
  но не устанавливает программное обеспечение.
- Перед обновлением рекомендуется сохранить резервную копию SQLite.
- История пропусков сохраняется между перезапусками.

Версия 1.1.1
------------

Добавлено:
- Параметр release_filter для выбора способа фильтрации выпусков GitHub.
- Поддержка режимов фильтрации strict, github и version.

Улучшено:
- Обработка временных сетевых ошибок Telegram.

Исправлено:
- Устранён избыточный вывод трассировок при сбоях соединения с Telegram.

Версия 1.1.0 — 01.11.2026
------------------------

Добавлено:
- Поддержка необязательного личного ключа доступа GitHub через переменную
  GITHUB_TOKEN в файле .env. При отсутствии ключа запросы выполняются
  без авторизации.
- Команда /pending для повторной отправки уведомлений о неподтверждённых
  обновлениях с кнопкой «Версия обновлена».
- Встроенное меню команд Telegram с описаниями доступных команд.
- Библиотека packaging для сравнения номеров версий.

Улучшено:
- Сообщения об ошибках config.yaml теперь содержат индекс записи
  software[N] и, если доступны, название программы и её идентификатор.
- Защита журналов: скрытие известных секретов в сообщениях и исключениях,
  ограничение подробности журналирования httpx и httpcore.
- Определение обновлений GitHub: для стабильного канала выбирается
  максимальная стабильная версия из списка выпусков, а не только выпуск,
  помеченный GitHub как последний.

Исправлено:
- Более старая версия больше не должна считаться новым обновлением
  только из-за несовпадения номеров версий.
- Добавлена отдельная обработка ошибок авторизации и ограничений
  запросов GitHub.

Примечания:
- После обновления зависимостей необходимо выполнить:
  pip install -r requirements.txt
- Существующие записи журналов с секретами автоматически не очищаются.
- Повторное уведомление не изменяет сохранённую текущую версию программы.

Версия 1.0.1 — 25.10.2026
--------------------------

Исправлено:
- Обработка сигнала SIGTERM при завершении работы ReleaseRadar.

Версия 1.0.0 — исходный выпуск
-----------------------------

- Отслеживание обновлений программ через GitHub и GitLab.
- Настройка отслеживаемых программ через config.yaml.
- Периодическая проверка обновлений.
- Уведомления через Telegram с возможностью подтверждения обновления.
- Хранение состояния отслеживаемых программ.
- Команды проверки и просмотра состояния.
- Работа в качестве службы Linux.

Примечание: точная дата первоначального выпуска здесь не указана.
